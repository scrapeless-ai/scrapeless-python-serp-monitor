# Download the starter project

[Open the starter ZIP file](scrapeless-serp-starter.zip), then click **Download raw file** on its GitHub file page.

1. Save and extract `scrapeless-serp-starter.zip`.
2. Open `START-HERE.txt`, or follow the [technical walkthrough](../docs/blog.en.md).
3. Run commands from the extracted `scrapeless-serp-starter` folder.

The ZIP contains runnable Python files, sample configuration and the MIT license. It contains no real API key, database or pre-collected results. Real collection requires your own Scrapeless API key and account credits. Access to a private repository requires an authorized GitHub account.
